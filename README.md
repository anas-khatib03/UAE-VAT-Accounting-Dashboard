# UAE VAT Accounting Dashboard

## Project Overview

An Excel-based accounting and VAT reporting dashboard developed to organize financial transactions, calculate VAT, reconcile VAT amounts, and present key accounting information in a structured dashboard.

## Project Objectives

* Record and organize accounting transactions
* Track sales, purchases, and related VAT information
* Calculate Output VAT and Input VAT
* Summarize VAT information for reporting
* Perform VAT reconciliation
* Present key financial and VAT information through an Excel dashboard

## Key Features

* Transaction register
* Customer and supplier information
* VAT calculations
* VAT summary
* VAT reconciliation
* Accounting data organization
* Dashboard and KPI presentation
* Excel-based financial reporting

## Tools & Skills

* Microsoft Excel
* Financial Accounting
* VAT Accounting
* UAE VAT fundamentals
* Data organization and reconciliation
* Excel formulas
* Financial reporting
* Dashboard development

## Project Purpose

This project was created as an independent portfolio project to demonstrate practical Excel, accounting, VAT, reconciliation, and financial reporting skills.

## Disclaimer

This is an independent educational and portfolio project. It is not an official accounting system or tax filing prepared for a real company.
